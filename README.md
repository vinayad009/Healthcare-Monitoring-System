# Healthcare Monitoring System

This project comes with a real-time healthcare monitoring system driven by GenAI with synthetic data generation using GANs and the use of LightGBM in disease prediction. The system addresses critical gaps in healthcare as it ensures that data privacy improves model robustness, and timely delivery of personalized health messages. This integrated approach aims at improving proactive healthcare delivery and contributing to the evolution. of patient-centered healthcare systems.

## Install

1. Python3
2. Django

## Usage

Run the following command to run the Django server locally:
```
python3 manage.py runserver
```
OR
```
python manage.py runserver
```

Incase of any changes to models. Ensure to run the below 2 commands to reflect the changes in the project:
```
python3 manage.py makemigrations
python3 manage.py migrate
```
OR
```
python manage.py makemigrations
python manage.py migrate
```
